# Wave modeling

Paint a velocity model (dark = fast), switch to **Source** and click to fire a
Ricker pulse, then press **Play**. Use the **Equation** menu to compare acoustic
(4th order), visco-acoustic, and elastic P-SV propagation through the same model.

<iframe src="../assets/modeling.html" width="100%" height="660"
        style="border:1px solid var(--md-default-fg-color--lightest); border-radius:10px"
        loading="lazy" title="Wave modeling"></iframe>

The elastic option uses a vertical point force, so you can see the P-wave, the
slower S-wave, and mode-converted energy at velocity contrasts.
