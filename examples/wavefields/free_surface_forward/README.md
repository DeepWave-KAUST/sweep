# Free Surface Forward

Forward-only free-surface visualization examples.

- `acoustic_free_surface.py`: compare acoustic snapshots and seismograms with and without `free_surface=True`
- `elastic_free_surface.py`: compare elastic `vz` snapshots and seismograms with and without `free_surface=True`

Run:

```bash
python acoustic_free_surface.py
python elastic_free_surface.py
```
